# 菜品配图说明

本目录下 74 张菜品图（`<food_id>.jpg`，736×552，4:3）为本项目**用 AI 图像生成模型统一制作**，
不属于任何第三方图库，无外部版权授权依赖，可随项目一起分发，仅用于教学演示。

- 生成方式：按菜品逐一构造提示词（主体食材 + 餐具 + 布光 + 构图 + 负面约束），
  统一为「45 度俯拍、自然侧光、虚化木质桌面背景、白瓷/砂锅/竹笼盛具」的餐厅菜单风格。
- 后处理：居中裁切为 4:3，缩放到 800×600，再裁掉生成工具烙在右下角的水印
  （底部 48px、左右各 32px），最终 736×552，JPEG 质量 88，全目录约 6.6 MB。
- 全部为无标识的原图内容，页面展示时不再需要渐变遮罩遮挡水印。

若后续替换为真实拍摄图，只需保持同名（`<food_id>.jpg`）覆盖即可，
模板与数据库中的 `foods.image_url` 无需改动（建议仍使用 4:3 比例）。
