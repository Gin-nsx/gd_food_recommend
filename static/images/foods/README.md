# 菜品配图说明

本目录下 74 张菜品图（`<food_id>.jpg`，800×600）为本项目**用 AI 图像生成模型统一制作**，
不属于任何第三方图库，无外部版权授权依赖，可随项目一起分发，仅用于教学演示。

- 生成方式：按菜品逐一构造提示词（主体食材 + 餐具 + 布光 + 构图 + 负面约束），
  统一为「45 度俯拍、自然侧光、虚化木质桌面背景、白瓷/砂锅/竹笼盛具」的餐厅菜单风格。
- 后处理：居中裁切为 4:3，缩放到 800×600，JPEG 质量 86，全目录约 7 MB。
- 图片右下角带有生成工具的水印，页面展示时由卡片底部渐变遮罩覆盖（见各模板
  `.food-image::after` 样式），不影响版面观感。

若后续替换为真实拍摄图，只需保持同名（`<food_id>.jpg`）覆盖即可，
模板与数据库中的 `foods.image_url` 无需改动。
